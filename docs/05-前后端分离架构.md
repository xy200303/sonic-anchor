# 智能助播前后端分离架构

## 组件职责

```text
直播伴侣 -> desktop -> backend -> 抖音 OpenAPI
抖音平台 -> backend HTTP callback -> Redis -> WebSocket -> desktop
frontend -> backend admin API -> PostgreSQL
```

- `desktop` 保留 FFmpeg、WebAudio、麦克风、音频缓存和直播控制。
- `frontend` 提供浏览器管理后台。
- `backend` 保存平台密钥，接收并验签互动数据，向桌面端转发事件。

## 抖音直播流程

1. 直播伴侣使用 `-token=xxx` 启动桌面端。
2. 桌面端调用 `/api/desktop/live/start`。
3. 后端获取 `access_token` 和直播间信息。
4. 后端启动 `live_comment` 数据推送任务。
5. 抖音调用 `/callbacks/douyin/live-data/:key`。
6. 后端验签、去重、存储并通过 Redis 发布事件。
7. WebSocket Hub 将事件推送到对应桌面端。

## 安全边界

- `AppSecret`、推送签名密钥、AI 和 TTS 密钥不得进入桌面安装包。
- 数据回调使用原始请求体参与签名校验。
- 桌面端 WebSocket 使用短期会话票据。
- 生产环境通过 HTTPS/WSS 暴露服务。
